# Security Policy

## Supported Versions

The following versions of Glacia packages are currently supported with security updates:

| Package | Version | Supported |
| :--- | :--- | :--- |
| `glacia` | `>= 0.5.0` | :white_check_mark: |
| `glacia-native` | `>= 0.5.0` | :white_check_mark: |
| `glacia-tokens` | `>= 0.5.0` | :white_check_mark: |
| `< 0.5.0` | Legacy releases | :x: |

## Reporting a Vulnerability

If you discover a potential security issue or vulnerability in Glacia, please do **NOT** open a public issue on GitHub.

Instead, please report security concerns privately:
- **Author:** Binyam Feyissa
- **GitHub Security Advisories:** [Report a private vulnerability](https://github.com/binyamfeyissa/Glacia/security/advisories/new)
- **Email:** Direct inquiries via [github.com/binyamfeyissa](https://github.com/binyamfeyissa)

Please provide:
1. A description of the vulnerability.
2. Steps to reproduce or proof-of-concept code.
3. Affected package versions and browser/runtime environment.

We take security vulnerabilities seriously and will review and respond promptly.
